# 🧠 Python Quiz Game
A simple Python Quiz Game where the user answers 5 multiple-choice questions and gets a score based on their correct answers.
# 👉🏻 Features
--> Contains 5 multiple-choice questions
--> Displays options for each question
--> Checks the user's answer
--> Calculates the final score
--> Shows the result at the end
# Technologies Used 
--> Python
# ▶️ How to Run 
--> Download or clone this repository.
--> Open the python file.
--> Run the program.
--> Choose the correct option for each question.
--> Check your final score.
# 🎯 Purpose
This project was created to practice basic Python concepts such as:
--> Lists
--> Loops
--> if-else conditions
--> User input
--> Comparing answers
--> Score calculation
